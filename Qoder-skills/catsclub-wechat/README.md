> 将 Markdown / 纯文本一键转换为微信公众号排版，6 种品牌风格 + 幽默元素体系 + 🐾 品牌签名 + 智能配图建议。

## 工作流程

### 总览

```
用户触发技能 → AI 复制 studio.html 到工作目录 → 浏览器打开排版器
     ↓
用户在浏览器中编辑 Markdown → 实时预览手机端效果
     ↓
点击「复制全文」→ 粘贴到微信公众号编辑器
     ↓
在公众号中替换图片占位卡槽为真实图片 → 发布
```

### 详细步骤

| 步骤 | 谁做 | 做什么 |
|------|------|--------|
| 1 | AI | 将 `assets/studio.html` 复制为 `mp-studio.html` |
| 2 | AI | 用 `open` / `xdg-open` 在浏览器中打开 |
| 3 | 用户 | 在左侧编辑器粘贴/编写 Markdown 内容 |
| 4 | 用户 | 选择风格（罗马废墟/午夜广场/通关手册等） |
| 5 | 用户 | 可选：拖入本地图片到「图片台」预览 |
| 6 | 用户 | 可选：使用快捷按钮插入幽默元素 |
| 7 | 用户 | 查看右侧手机预览，确认效果 |
| 8 | 用户 | 点击「复制全文 → 粘贴到公众号」 |
| 9 | 用户 | 在公众号编辑器中点击占位图 → 上传真实图片替换 |

| 用户说 | AI 执行 |
|--------|---------|
| "排版" / "打开排版器" / "狲熊排版" | 打开中控台 |

| "换个风格" / "用 xxx 风格" | 打开中控台，提示切换风格 |

**AI 的自动行为范围：**
- 复制 `studio.html` 到工作目录

## Markdown 语法速查

### 标准 Markdown（直接支持）

```markdown
# H1 标题
## H2 标题
### H3 标题

**加粗**  *斜体*  ==高亮==

> 引用块

- 无序列表项
1. 有序列表项

---                  分隔线

| 列1 | 列2 |
|-----|-----|
| 内容 | 内容 |
```

### 扩展语法（狲熊专属）

```markdown
>>> 导语段落（文章开头的引导性段落）

!!! tip 小贴士        提示框（4 种类型）
提示内容              - tip 小贴士
!!!                   - note 注意
                      - warn 警告
!!! warn 警告         - info 信息
警告内容
!!!

‖ 金句内容 ‖          金句标记

![A]段落内容           首字下沉（A 为首字字母）

--- 作者：xxx         落款签名

[sign2]               双角色签名（兔狲+猫熊头像）
```

### 幽默元素语法

```markdown
((🐦 兔狲的内心吐槽))     内心OS · 锈橙色
((🦉 猫熊的冷静观察))     内心OS · 深蓝色
((🙈 读者的真实反应))     内心OS · 灰色

{{🎯 核心笑点}}           包袱标记 · 锈橙底
{{🪞 反讽标记}}           包袱标记 · 深蓝底
{{⚡ 顿悟时刻}}           包袱标记 · 金箔底

🐱 兔狲：台词             角色对话 · 锈橙左边框（带兔狲头像）
🐼 猫熊：台词             角色对话 · 深蓝左边框（带猫熊头像）
🤖 AI助手：台词           角色对话 · 紫色左边框
👤 路人：台词             角色对话 · 灰色左边框

[quest]任务内容[/quest]   任务卡片
[hp:75/100]              血条进度
[buff]加速思考[/buff]     Buff 标签
[debuff]完美主义[/debuff] Debuff 标签
```

### 图片语法

```markdown
![[1]]              单张配图
![[1|cover]]        封面图（全宽）
![[1|quote]]        引用截图（左侧色条）
![[1,2]]            双图并排
![[1,2,3]]          三图并排
![[cover]]          品牌封面 GIF
```

> 图片在预览时显示本地图片（从图片台拖入），复制时自动变为占位 SVG 卡槽。粘贴到公众号后点击占位图即可替换。

## 图片工作流（重要）

微信公众号只接受素材库图片，不支持外部链接。因此排版器采用**占位卡槽**机制：

```
排版器中拖入图片（预览） → 复制时自动生成 SVG 占位图
→ 粘贴到公众号 → 点击占位图 → 从素材库选择真实图片替换
→ 点击图片选择「自适应」确保填满边框
```

**关键技巧**：替换图片后如果没有贴满边框，点击图片选择「自适应」即可。

## 内容审视（智能配图建议）

排版器内置内容分析模块，自动检测以下问题：

| 检测项 | 触发条件 |
|--------|---------|
| 文章过短 | 全文 < 200 字 |
| 图片偏少 | 图片数 < 章节数 × 0.5 |
| 长段落无图 | 连续 300 字无图片 |
| H2 后缺图 | H2 标题后 3 个内容块内无图片 |
| 导语后缺图 | 导语段落后无图片 |
| 缺导语 | 长文无 `>>>` 导语 |
| 章节缺分隔 | 3+ 章节但分隔符不足 |

检测到缺图位置时，自动生成 6 种 AI 插图提示词：封面图、场景图、流程图、界面截图、金句图、角色插画。

## 技术约束（微信公众号白名单）

**可用：** 内联 `style`、`<table>`、`<div>`、`<p>`、`<h1>`-`<h3>`、`<img>`、`<strong>`、`<em>`、`background-color`、`border`、`padding`、`margin`、`color`、`font-size`、`line-height`、`border-radius`

**禁用：** `<style>` 标签、class 选择器、`display:flex`、`position:absolute`、`box-shadow`、`linear-gradient`、`opacity`、SVG、外部字体、CSS 变量、动画

排版器已内置所有约束，生成的 HTML 自动合规，无需用户操心。

## 常见问题

**Q：浏览器打开后显示旧内容？**
A：按 `Cmd+Shift+R`（Mac）或 `Ctrl+Shift+R`（Windows）硬刷新。

**Q：角色对话的头像不显示？**
A：确保使用的是最新版 studio.html。头像使用 Base64 内嵌，不依赖外部文件。

**Q：复制到公众号后样式丢失？**
A：不要在公众号编辑器里修改 HTML，只替换图片。排版器输出的 HTML 已针对微信白名单优化。

**Q：首字下沉怎么触发？**
A：手写 `![首字]段落内容` 或点击左侧「A 首字」按钮插入模板后修改。

**Q：如何自定义品牌色？**
A：使用左侧「品牌色」颜色选择器，一键覆盖当前风格的点缀色。
