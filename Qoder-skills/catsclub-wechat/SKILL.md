# 狲熊排版器（CatsClub-Wechat）

把任何文本内容变成狲熊AI训练营品牌风格的公众号文章排版。**6 种狲熊专属风格 + 幽默元素体系 + 🐾 品牌签名 + 内容审视**，实时预览，一键复制粘贴到微信公众号编辑器。

## 核心功能

- **6 种狲熊风格**：罗马废墟 / 午夜广场 / 通关手册 / 短随想 / 幽默小故事 / 金箔拼贴
- **幽默元素体系**：内心OS、包袱标记、角色对话、任务卡片、血条、Buff/Debuff
- **🐾 品牌签名**：所有文章末尾自动附加狲熊AI训练营签名
- **内容审视**：主动检测缺插图位置并生成AI插图提示词
- **图片排版**：5 种角色（封面 / 配图 / 引用 / 双图 / 三图），每种风格独立设计的图片框
- **实时中控台**：浏览器直接打开，左侧编辑右侧手机预览
- **图片占位卡槽**：复制到公众号后，每张图片是带样式的占位 SVG，用户点击即可替换为真实图片
- **品牌色定制**：一键覆盖任何风格的点缀色

## 默认行为：打开中控台

当用户触发此技能时，**默认直接打开中控台**。

**执行步骤（严格按顺序）：**

```bash
# 1. 定位 skill 目录（Qoder 环境自动注入）
SKILL_PATH="${SKILL_DIR:-$(dirname "$0")}"

# 2. 把中控台 HTML 复制到用户工作目录
cp "$SKILL_PATH/assets/studio.html" ./mp-studio.html

# 3. 用浏览器打开（自动检测系统）
# macOS:
open ./mp-studio.html
# Linux:
xdg-open ./mp-studio.html
# Windows (在 WSL 中):
cmd.exe /c start mp-studio.html
```

🔴 **CHECKPOINT · 用户确认**：复制完成后告知用户「中控台已准备就绪，即将在浏览器中打开」，等待用户确认后再执行 open 命令。

**失败模式与恢复：**

| 症状 | 一线修复 | 仍失败兜底 |
|------|---------|-----------|
| `cp: No such file` — studio.html 不存在 | 检查 `$SKILL_PATH` 是否正确指向 skill 目录 | 从 GitHub 手动下载：`curl -L github.com/IvyTengLi/sunxiong/raw/main/.qoder/skills/CatsClub-Wechat/assets/studio.html -o mp-studio.html` |
| `open: command not found` — macOS 无 open | 尝试 `xdg-open`（跨平台兼容） | 提示用户手动双击 mp-studio.html 打开 |
| 浏览器打开但显示空白 | 检查文件大小是否为 0；重新复制 | 用文本编辑器直接打开 studio.html 另存为 |
| Qoder 网页端 iframe 限制 | 提供下载链接让用户本地打开 | 生成 HTML artifact 供用户复制源码 |

中控台会在浏览器中弹出。用户在浏览器里完成排版后，点击「复制全文」按钮，然后粘贴到公众号编辑器即可。

**如果用户在 Qoder 网页端使用**，可以直接读取 `assets/studio.html` 并作为 HTML artifact 输出（但 iframe 限制可能影响 Clipboard API，推荐用户最终下载到本地浏览器使用）。

## 图片工作流

由于微信公众号对图片有严格限制（只接受微信素材库的图片），我们的工作流是：

1. **预览阶段**：用户在中控台「图片台」拖入本地图片，仅用于实时预览效果
2. **复制阶段**：复制时图片自动变成"占位 SVG"，但保留外层风格化边框
3. **粘贴阶段**：粘贴到公众号编辑器，图片占位卡槽完整显示
4. **替换阶段**：用户在公众号编辑器里点击占位图，选择真实图片替换
5. **关键技巧**：替换后图片可能没贴边框，**点击图片选择「自适应」**，图片就会完美填满边框

外层 `<section>` 边框、图注、引用标签全部保留 ✅

## 内容审视

中控台自动分析文章内容，检测以下问题：

| 规则 | 触发条件 | 级别 |
|------|----------|------|
| 文章过短 | 全文 < 200 字 | 警告 |
| 图片偏少 | 图片数 < 章节数 × 0.5 | 建议 |
| 长段落无图 | 连续 300 字无图片 | 建议 |
| H2后缺图 | H2 后 3 个 token 内无图片 | 建议 |
| 导语后缺图 | 导语后无图片 | 建议 |

检测到缺图时，自动生成 6 种类型 AI 插图提示词：封面图、场景图、流程图、界面截图、金句图、角色插画。

## 技术约束

所有输出 HTML 必须遵守微信公众号编辑器规则：

**可用：** 纯内联 style、`<table>`、`<div>`、`<p>`、`<h1>`-`<h3>`、`<img>`、`<strong>`、`<em>`、`background-color`、`border`、`padding`、`margin`、`color`、`font-size`、`line-height`、`letter-spacing`、`border-radius`

**禁用：** `<style>` 标签、class 选择器、`<section>`（微信会转为`<p>`）、`display:flex`、`position:absolute/relative`、`box-shadow`、`text-shadow`、`linear-gradient`、`opacity`、SVG、外部字体、CSS 变量、动画、深色背景

## 🚫 反例与黑名单

**以下操作会破坏排版效果，必须避免：**

| 反模式 | 为什么危险 | 正确做法 |
|--------|-----------|---------|
| 在公众号编辑器里直接修改 HTML | 微信会过滤 `display:flex`、`position:absolute`、SVG 等，导致样式失效 | 只在中控台编辑，复制后只替换图片，不修改文字样式 |
| 使用外部字体或 `@font-face` | 微信不支持外部字体加载，会导致字体回退为系统默认 | 使用系统字体栈（`-apple-system`、`PingFang SC`、`Noto Sans SC`） |
| 深色背景 + 白色文字 | 微信深色模式会反转颜色，导致文字不可见 | 始终使用浅色底（#F0F0F0）+ 深色文字 |
| 直接粘贴 `**加粗**` 到公众号 | 微信不支持 Markdown，会显示原始星号 | 在中控台渲染后复制，让加粗变成 `<strong>` 标签 |
| 使用 `<section>` 标签包裹内容 | 微信会自动把 `<section>` 转为 `<p>`，破坏布局 | 使用 `<table>` 或纯 `<div>` 布局 |
| 插入超过 2MB 的 GIF | 微信素材库有大小限制，大 GIF 会上传失败 | 使用 Cover.gif（73KB）或压缩后的动效 |
| 在 Markdown 里写 `display:flex` | 即使写进 Markdown，复制到微信后也会被过滤 | 使用 `<table>` 实现横向排列（双图/三图） |
