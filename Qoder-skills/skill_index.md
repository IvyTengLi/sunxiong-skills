## 快速选择指南

### 需要生成视觉内容？
→ 使用 **catclub-card**

- 单张阅读卡片 → `-l` 长图
- 数据可视化 → `-i` 信息图
- 长篇内容分多张 → `-m` 多卡
- 手绘风格笔记 → `-v` 视觉笔记
- 故事漫画化 → `-c` 漫画
- 结构化流程图 → `-w` 白板
- 一句话金句 → `-b` 大字

### 需要公众号排版？
→ 使用 **catsclub-wechat**

- 品牌故事/正式介绍 → 罗马废墟风格
- 技术教程/深潜解析 → 午夜广场风格
- 课程讲义/操作手册 → 通关手册风格
- 碎片思考/灵感记录 → 短随想风格
- 行业吐槽/轻松话题 → 幽默小故事风格
- 成就展示/高端内容 → 金箔拼贴风格

### 需要建立品牌规范？
→ 使用 **brand-voice-builder**

- 定义品牌语气和禁飞区 → BrandVoice.md
- 产品描述（一句话/一段话/一页纸） → Product.md
- 网页设计系统（颜色/字体/组件） → Design.md
- QoderWork规则文件 → AGENTS.md
