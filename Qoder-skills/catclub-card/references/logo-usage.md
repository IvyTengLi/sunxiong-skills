# Logo 使用规范

> 完整规范见 `references/logo-usage.md`。本文档为 SKILL.md 的配套 reference，供铸卡执行时查阅。

## 资产清单

| 文件 | 内容 | 线条颜色 | 最佳对比背景 | 最差对比背景 |
|------|------|---------|-------------|-------------|
| `logo-light.png` | 完整版（图形+「狲熊AI训练营」文字） | 黑线 `#1A1A1A` | `#F0F0F0` 浅色 | `#0D0D12` 深色（文字消失） |
| `logo-dark.png` | 完整版（图形+「狲熊AI训练营」文字） | 金线 `#C9A227` | `#0D0D12` 深色 | `#F0F0F0` 浅色（图形消失） |
| `logo-icon.png` | 纯图形（无文字） | 金线 `#C9A227` | 深色背景 ≥ `#2A2A2A` | `#F0F0F0` 浅色（≈1.5:1，隐形） |
| `logo-icon-dark.png` | 纯图形（无文字） | 白线 `#F0F0F0` | 深色背景 ≥ `#1A1A1A` | `#F0F0F0` 浅色（对比度低） |

**核心原则：狲熊是显眼包，Logo 必须被一眼看见。** 不允许以「内容为王」为借口把 Logo 缩成蚂蚁。所有 Logo 摆放决策以「第一眼能否看到 Logo」为唯一检验标准。

**关键洞察：`logo-icon.png`（金线）和 `logo-dark.png`（金线文字）在 `#F0F0F0` 浅色背景上对比度极差（≈1.5:1），裸放等于隐形。金线必须落在深色背景上。**

## 默认无 Logo 策略

自本版本起，CatClub-Card 默认**不放置 Logo**，仅保留底部 `.brand-signature`（🐾 狲熊AI训练营 + slogan）。

**默认行为（无 `--logo` 参数）：**
1. 首次生成时，`{{LOGO_FILE}}` 注入 1px 透明 GIF 占位图：`data:image/gif;base64,R0lGODlhAQABAIAAAAAAAP///yH5BAEAAAAALAAAAAABAAEAAAIBRAA7`
2. `.brand-logo` 容器存在但视觉上不可见
3. 生成后展示 Logo 审查报告，根据模具类型、背景色调推荐最佳 Logo 动作
4. 用户确认后，基于已有 HTML 快速替换 Logo 路径并重新截图，输出 `{name}_branded.png`

**可选参数 `--logo`：**
- `--logo`：跳过审查报告，直接按决策矩阵自动添加 Logo
- `--logo=stamp`：强制盖印
- `--logo=embed`：强制镶嵌
- `--logo=sign`：强制落款
- `--logo=ghost`：强制浮水印

## Logo 的四种动作（从「形式分类」到「动作语义」）

Logo 不是被「放置」的，Logo 是被「盖上去」的。

| 动作 | 视觉结果 | 适用场景 | 尺寸 | 禁忌 |
|------|---------|---------|------|------|
| **盖印** | 微旋转（3-10°），无框，透明底，像火漆印 | 信息图标题旁、海报角落、任何需要「被盖上去」气质的画面 | 画布≥1080px: 200-280px; 画布900px: 150-200px; 画布<900px: 100-140px | 禁止黑框、禁止正放（像印刷品而非印章） |
| **镶嵌** | Logo落入画面天然深色区，无额外支撑 | 图表黑底栏、暗色卡片、漫画gutter、视觉笔记深色色块 | 占深色区宽度的 60-80%，最小 80px，最大 200px | 禁止在浅色区硬造深色块来「托住」它 |
| **浮水印** | 大尺度（400-600px），极低透明度（0.06-0.10） | 极简画面、需要品牌气场弥漫、长图大面积留白 | 400-600px（占画布宽度 37-55%） | 禁止透明度>0.12，那会干扰阅读 |
| **落款** | 完整版（含文字），小尺度（48-64px），低透明度 | 长图底部、多卡边缘、任何需要「签名」而非「标识」的位置 | 高度 48-64px | 禁止放大到>100px，那会像广告牌 |

**动作选择优先级：盖印 > 镶嵌 > 落款 > 浮水印。** 能盖印就不镶嵌，能镶嵌就不落款，能落款就不浮水印。

## Logo 决策模型：三维判断法

不要问「这是什么模具」，要问三个问题：

```
维度1：画面主色调
  ├─ 浅色（#F0F0F0 / #E8E8E8 / 白色为主）→ 金线Logo需深色支撑（盖印时用透明底+旋转，或镶嵌到深色区）
  ├─ 深色（#0D0D12 / #1A1A1A / 黑色为主）→ 金线Logo可直接镶嵌，黑线需浅色支撑
  └─ 混合（深浅区域都有）→ 进入维度2

维度2：Logo目标位置的背景色
  ├─ 位置背景为深色（≥ #2A2A2A）→ 金线可直接镶嵌
  ├─ 位置背景为浅色（≤ #E0E0E0）→ 盖印（透明底+旋转），或换位置找深色区镶嵌
  └─ 位置背景为彩色/纹理 → 计算对比度，< 3:1 时必须换位置

维度3：该位置的视觉竞争
  ├─ 周围无其他图形/大文字 → 可以盖印（大尺度+旋转）
  ├─ 周围有中等密度内容 → 盖印（中等尺度）或镶嵌
  └─ 周围极度密集 → 落款（小尺度完整版），或放弃该位置
```

**决策示例：**
- 信息图，浅色背景，右上角空白 → 盖印（透明底logo-icon，旋转-8°，243px）
- 信息图，有黑色对比卡片 → 镶嵌（金线图形直接落在黑色卡片上）
- 长图，顶部有品牌区 → 落款（完整版横置，小尺度）
- 海报，深色背景，顶部有标题 → 盖印（透明底logo-icon-dark，旋转5°）
- 漫画分镜间有深色 gutter → 镶嵌（金线图形落在gutter上）
- 视觉笔记，密集涂鸦 → 落款（小尺度完整版）或 找一处深色留白镶嵌

## 盖印实现规范

**核心原则：Logo 是一枚被盖上去的印章，不是被印刷出来的图案。**

**CSS 模板：**
```css
.brand-logo-stamp {
  position: absolute;
  top: calc(var(--pad-y) * 0.35);
  right: calc(var(--pad-x) * 0.35);
  z-index: 101;
  width: calc(var(--base-text) * 6.75);
  height: calc(var(--base-text) * 6.75);
  display: flex;
  align-items: center;
  justify-content: center;
  transform: rotate(-8deg);
}
.brand-logo-stamp img {
  width: 100%;
  height: 100%;
  object-fit: contain;
  display: block;
}
```

**旋转角度：**
- 默认：-8°（逆时针，像随手盖下的印章）
- 范围：3-10°，正数顺时针，负数逆时针
- 禁止 0°：正放是工厂，斜放是手作

**尺寸规则：**
- 画布 ≥ 1080px → 200-280px（`base-text × 5.5 至 7.5`）
- 画布 900px → 150-200px（`base-text × 4.0 至 5.5`）
- 画布 < 900px → 100-140px（`base-text × 3.0 至 4.0`）
- **禁止 < 80px**：狲熊不是蚂蚁

**位置规则：**
- 默认：右上角，与边缘保持 `pad-x/y × 0.35` 距离
- 标题短时：标题右侧空白区，与标题顶部对齐
- 禁止放在画面正中央：印章不会盖在正中央，那是印刷品

**透明底要求：**
- 必须使用透明背景版 `logo-icon.png`（已处理背景透明）
- 禁止加任何边框、阴影、圆盘：印章本身就是完整的印记

**防重叠检测：**
Logo与最近文字/图形元素之间必须保留 ≥ 32px 间距。若重叠，优先调整旋转角度或位置，而非缩小Logo。

## 镶嵌实现规范

**核心原则：不造支撑，借画面的天然深色区域。**

**识别画面中的天然深色区：**
- 信息图的黑色对比卡片（如 BEFORE/AFTER 中的暗色栏）
- 图表的深色背景区域
- 暗色模式下的任何深色块
- 漫画的 gutter（分镜间隙）
- 视觉笔记的深色色块/阴影区

**实现：**
```css
.logo-embedded {
  position: absolute;
  z-index: 101;
}
.logo-embedded img {
  width: 120px;
  height: auto;
  display: block;
}
```

**尺寸：** 占深色区宽度的 60-80%，最小 80px，最大 200px。

**优势：** 不破坏画面构图，Logo自然融入；金线在深色背景上对比度极佳（> 8:1）。

## 浮水印实现规范

**CSS 模板：**
```css
.logo-ghost {
  position: absolute;
  top: 55%;
  left: 50%;
  transform: translate(-50%, -50%);
  z-index: 1;
  opacity: 0.08;
  pointer-events: none;
}
.logo-ghost img {
  width: 450px;
  height: 450px;
  display: block;
}
```

**参数：**
- 尺寸：400-600px（占画布宽度 37-55%）
- 透明度：0.06-0.10（必须低于 0.12，否则干扰阅读）
- 位置：默认居中偏下（`top: 55%`）；若内容重心偏上，可偏置到下方 1/3

**使用场景：**
- 极简画面、需要品牌气场弥漫
- 长图大面积留白
- 任何需要「狲熊无处不在」但又不干扰阅读的场景

## 各模具默认 Logo 策略

| 模具 | 默认是否显示 | 默认形式 | 备选形式 | 说明 |
|------|-------------|---------|---------|------|
| `-l` 长图 | 否（需 `--logo` 或用户确认） | 落款（完整版小尺度） | 浮水印 | 长图底部签名，大面积留白时加浮水印 |
| `-i` 信息图 | 否（需 `--logo` 或用户确认） | 盖印（透明底+旋转） | 镶嵌（落入深色区） | 优先盖印，有天然深色区时镶嵌 |
| `-m` 多卡 | 否（需 `--logo` 或用户确认） | 落款（首卡完整版）+ 盖印（其他卡） | — | 首卡建立品牌，后续卡盖印保持识别 |
| `-v` 视觉笔记 | 否（需 `--logo` 或用户确认） | 盖印（可微旋转 5-15°） | 镶嵌（落在深色涂鸦区） | 手绘风格允许更大角度旋转 |
| `-c` 漫画 | 否（需 `--logo` 或用户确认） | 镶嵌（落在 gutter 深色区） | 落款（小尺度完整版） | 封面可盖印，内页优先镶嵌 |
| `-w` 白板 | 否（需 `--logo` 或用户确认） | 盖印 | 落款 | 白板标题栏旁通常有空间盖印 |
| `-b` 大字 | 否（需 `--logo` 或用户确认） | 镶嵌 | 落款 | 和紙左下签名栏自然融入 |

## 审查报告触发条件

仅当**未使用 `--logo` 参数**时触发：
1. 生成无 Logo 版本 PNG
2. 向用户展示审查报告（模具类型 / 画布尺寸 / 背景色调 / 推荐动作 / 推荐文件 / 尺寸 / 位置 / 理由）
3. 询问用户是否添加 Logo
4. 用户确认后，基于已有 HTML 迭代生成 `{name}_branded.png`

## 禁止条款

| # | 禁止项 | 原因 |
|---|--------|------|
| L1 | 在浅色背景上裸放 `logo-icon.png`（金线）不加旋转 | 对比度 ≈ 1.5:1，等于隐形；正放像印刷品，不是印章 |
| L2 | 在浅色背景上使用 `logo-dark.png`（金线完整版） | 文字可读，图形消失，视觉断裂 |
| L3 | Logo 高度 < 80px（手机端 < 60px） | 狲熊不是蚂蚁 |
| L4 | 所有模具统一使用同一种 Logo 动作 | 信息图需要盖印，长图需要落款，需求完全不同 |
| L5 | 以「内容为王」为由将 Logo 透明度压到 < 0.30 | 那是水印，不是品牌标识 |
| L6 | 在浅色区强行造深色圆盘/黑框来「托住」Logo | 破坏构图，违背盖印原则（印章不需要托盘） |
| L7 | 盖印时旋转 0° | 正放是工厂印刷，斜放是手作盖章 |
| L8 | 盖印时加边框、阴影、圆盘 | 印章本身就是完整的印记，不需要额外装饰 |
